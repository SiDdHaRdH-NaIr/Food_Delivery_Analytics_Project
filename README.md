# Food Delivery Orders Analytics using Python (Pandas + Matplotlib)

This project analyses food delivery performance using order data for 2024.  
The goal is to derive meaningful business insights such as top performing cities, best revenue generating cuisines, peak demand hours, service quality impact and overall operational KPIs.

---

## Project Overview

This case study demonstrates a real-world style analytics workflow:

- Data loading & cleaning
- Feature engineering (extracting hour, weekday, month)
- KPI summary (orders, revenue, cancellation rate, avg delivery time)
- Visual insights (city demand, cuisine revenue, hourly trend)
- Delivery time vs rating relationship
- Final business insights summary

The analysis was performed in **Jupyter Notebook** using:

- **Pandas** for data manipulation
- **Matplotlib** for visualization
- **Git** for version control & branch workflow

---

## Key Insights

| Insight Area | Observation |
|--------------|-------------|
| Top Order Cities | Bengaluru & Hyderabad lead in order volume |
| Highest Revenue Cuisines | Biryani & North Indian generate maximum revenue |
| Demand Peaks | Lunch (12–2 PM) & Dinner (7–10 PM) are peak hours |
| Average Delivery Time | ~35 minutes |
| Cancellation Rate | ~4% |
| Delivery Time vs Rating | Longer delivery time correlates with lower ratings |
