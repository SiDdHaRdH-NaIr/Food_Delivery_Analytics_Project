# Food Delivery Orders Analytics – Python Case Study

This project explores food delivery performance using real-world style order data from 2024.  
The goal was to understand demand patterns, revenue contribution by cuisines, busy hours, delivery efficiency, and customer experience metrics.

## What I did in this project

I followed a typical data analytics workflow:

- Loaded and cleaned the dataset
- Created new time-based features (month, weekday, hour)
- Calculated core business KPIs such as:
  - Total orders
  - Total revenue
  - Cancellation rate
  - Average delivery time
  - Average customer rating
- Visualised customer behaviour using bar charts, line charts and scatter plots
- Summarised final insights that would be useful for business decisions

The analysis was done in **Jupyter Notebook** using:

- **Pandas** for data manipulation
- **Matplotlib** for charts
- **GitHub** for version control and branch workflow

## Key Insights (from analysis)

| Insight | Findings |
|--------|----------|
| Highest order volume | Bengaluru & Hyderabad |
| Top revenue cuisines | Biryani and North Indian food |
| Busy periods | Lunch (12–2 PM) & Dinner (7–10 PM) |
| Avg delivery time | 35 minutes |
| Cancellation rate | 4% |
| Delivery time vs rating | Longer delivery time → ratings tend to drop |
